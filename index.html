Consulta SQL com JOIN

Artigos de um autor em um intervalo de datas, no banco do Conduit.

SELECT a.*
FROM article AS a
JOIN users AS u ON a.author_id = u.id
WHERE u.username = '1test'
  AND a.createdAt >= '2020-07-05'
  AND a.createdAt <  '2020-07-08'
ORDER BY a.createdAt DESC;

Destaque: testes de API do Conduit no Postman

Uma coleção completa que cobre a API inteira do Conduit, com cenários positivos e negativos e verificações automáticas em cada requisição.

44requisições
157verificações automáticas
5módulos da API
4métodos: GET, POST, PUT, DELETE

O que a coleção cobre

  • Cadastro e login: 16 cenários, incluindo e-mail sem @, campos vazios, usuário e e-mail já usados
  • Valor-limite: usuário com 41 caracteres e e-mail com mais de 254
  • Permissões: criar, editar e apagar sem login (401) e apagar artigo ou comentário de outra pessoa (403)
  • Artigos, perfis, tags e comentários: criação, edição, feed, filtro por tag, seguir e deixar de seguir
  • Dados dinâmicos: variáveis encadeiam uma requisição na outra, e scripts criam um segundo usuário para testar acesso indevido
  • Desempenho: cada resposta é checada para chegar em menos de 1 segundo
Baixar a coleção (.json)

Exemplo: apagar o artigo de outra pessoa

O sistema deve bloquear. O teste confere o código 403, o tempo de resposta e a mensagem.

pm.test("Assert response status code is 403", () => {
  pm.response.to.have.status(403);
});

pm.test("Assert response time is less than 1000ms", () => {
  pm.expect(pm.response.responseTime).to.be.below(1000);
});

pm.test("Assert response body is Forbidden", () => {
  pm.expect(pm.response.text().trim()).to.eql("Forbidden");
});
